# Changelog

## 0.1.0 — 2026-11-25

- Added `nbeamer`, a 16:9 slide class for Chinese and English presentations, with a shared layout grid, optional alignment guides, and font selection for LXGW WenKai, Fandol, or custom fonts.
- Set a one-grid gap between block titles and the first line of body text.
- Added `nbeamer-images` for image grids with explicit rows and columns, optional cell height, proportional scaling, center cropping, and width-limited captions.
- Added `nbeamer-code` for code listings with grid-aligned line spacing and automatic line wrapping.
- Added commands to install, update, and uninstall nbeamer in a personal TeX tree. The installer checks TeX Live dependencies and downloads the optional WenKai fonts as needed.
- Included [editable documentation and PDFs](docs/) for the class, both extensions, and layout design.
